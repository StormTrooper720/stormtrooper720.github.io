## A new design
I am currently updating my website to a new framework. The old design relied on Hugo which allowed me to use simple Markdown files to create a website out of.
This worked but I always felt it involved too much overhead with file management. I am now using Astro for my website with the [Astro-Keel theme](https://github.com/kpab/astro-keel/).
Astro functions similarly to Hugo allowing me to use simple Markdown files for pages, except it has way more functionality and feels easier to use, setup, and change.
I'm currently porting the old project pages to this new website, which shouldn't take too long - it's really just changing the image syntax.
